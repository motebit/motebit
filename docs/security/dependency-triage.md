# Production dependency triage — 2026-09-13

The release gate for dependency advisories is `pnpm audit --prod --audit-level=high` in CI (`.github/workflows/ci.yml`), raised from `critical` on 2026-09-13. A HIGH or CRITICAL advisory fails CI unless it is accepted explicitly in `package.json` → `pnpm.auditConfig.ignoreCves`, and every accepted CVE has a row below with a reachability argument and a **lift trigger**. A bare count threshold is not a policy; this ledger is.

Baseline before this pass (commit `2ff5740c`): 54 advisories — 23 high, 29 moderate, 2 low. After: 0 high not accepted, 2 high accepted (no fix exists), 4 moderate visible-and-documented, 1 low.

## Process

- Re-run `pnpm audit --prod` before each release; a new HIGH fails CI by construction.
- Adding to `ignoreCves` requires a row here with a reachability argument and a lift trigger in the same commit.
- Dependabot majors colliding with an override cap are a paired change (lift cap + bump + revalidate), per `.github/dependabot.yml` comments.
