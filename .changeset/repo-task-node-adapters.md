Node adapters for the repo-task run (governed repo change, milestone B build step 2), not yet wired to a command: a git tree reader that reads only the tip's tree (`git ls-tree` / `git cat-file` with isolated git config and literal pathspecs); a git change stager that never writes the worktree — new content goes to git's object store as blobs (`hash-object -w`), and the change commit is built on a private index with every path on stdin (`read-tree`, `update-index -z --index-info`, `write-tree`, `commit-tree -p <tip>`), touching no worktree file, repository index or ref, and refusing (no commit) any tree that is not exactly the staged adds and modifies of 100644 blobs; every git call runs in an isolated session against a private empty repository (its config written by us, the real object store via `GIT_OBJECT_DIRECTORY`, alternates honoured for reads), so the repository's own config is never read; the commit timestamp must be integer seconds (`@<secs> +0000`); and a durable JSON-lines receipt file. The governed-run receipts carry the call's real status (see the runtime changeset).
