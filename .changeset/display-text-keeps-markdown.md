Replies now keep their formatting: **bold** and _italic_ text, lists, paragraphs and code blocks reach you as the model wrote them. Before, the reply filter deleted everything between asterisks and collapsed all line breaks into single spaces, so key terms vanished and lists and code flattened. The intelligence-parity benchmark scored the same model request 4.2/10 through motebit against 7.7/10 sent directly (#1076).
